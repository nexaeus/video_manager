# Video Manager
## Built entirely in **Rust** by myself **Nexaeus**.
___
### Installation:

Clone the video manager repository.
```bash 
git clone https://github.com/nexaeus/video_manager.git
cd video_manager
```
Build
```bash
cargo build
```
Install binaries to your cargo installation dir which is added to PATH.
```bash
cargo install --path .
```

### Usage:

In your terminal window, type 
```bash
video-manager -h
``` 
or 
```bash
video-manager --help
```
to see usage details.
